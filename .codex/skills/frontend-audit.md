# Skill: Frontend Audit

Use this skill when asked to improve, redesign, polish, or fix frontend.

## Goal

Inspect the current frontend before coding so changes are grounded in the existing product.

## Steps

1. Inspect routes, layouts, components, styles, and design patterns.
2. Identify ugly, broken, inconsistent, unfinished, or confusing UI.
3. Prioritize pages by user impact:
   - landing/home
   - auth
   - dashboard
   - core product flows
   - settings/profile
   - admin/internal pages
4. Create `docs/FRONTEND_AUDIT.md` before major coding.
5. Include:
   - current UI problems
   - affected files
   - severity
   - proposed fix
   - implementation order
6. Never redesign blindly.
7. Do not start large UI rewrites before the audit exists.
