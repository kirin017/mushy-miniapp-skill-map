# Skill: Production Frontend

Use this skill before considering frontend work complete.

## Required Checks

1. Run lint.
2. Run typecheck.
3. Run build.
4. Check loading states.
5. Check error states.
6. Check empty states.
7. Check accessibility basics.
8. Check console errors.
9. Create final report.

## Accessibility Basics

Check:

- semantic buttons and links
- visible focus states
- usable color contrast
- alt text for meaningful images
- form labels
- keyboard navigation for important interactions

## Final Report

Create or update:

- `docs/FRONTEND_FINAL_REPORT.md`

Include:

- summary of changes
- files changed
- routes checked
- viewport checks
- commands run
- issues fixed
- known limitations
- recommended next steps
